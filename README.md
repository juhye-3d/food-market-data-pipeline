# Food Market Data Pipeline

식품 제조업 생산지수, 농산물 가격, 식품기업 실적을 수집·표준화하고 품질을 검증하는 CLI 기반 데이터 파이프라인입니다.

## 데이터 소스

- KOSIS API: 식료품 제조업 생산·출하·재고 월별 지수
- KAMIS HTML: 기간별 농산물 소매가격과 등락률
- CJ제일제당 IR PDF: 분기별 실적표 한 개
- 대체 소스: aT 기간별 소매가격 OpenAPI

## 핵심 요구사항

- 기간 범위를 지정한 백필
- 자연키 기반 멱등 적재와 중복 제거
- 재수집 시 과거 값 변경 감지
- 필수값, 건수 급감, 값 급변, 기간 누락 검사
- KAMIS HTML과 aT API의 동일 날짜·품목 교차 검증
- 모든 수집 실행과 품질 검사 결과 기록

## 현재 상태

소스 조사 단계입니다. 실제 샘플을 확보한 뒤 원본·표준·품질 스키마를 확정합니다.

자세한 조사 결과는 [`docs/source-investigation.md`](docs/source-investigation.md)를 참고하세요.
