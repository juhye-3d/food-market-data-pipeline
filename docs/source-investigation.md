# 소스 조사서

조사일: 2026-11-16

## 프로젝트 범위

식품 제조업 생산지수, 농산물 가격 및 식품기업 실적을 하나의 파이프라인에서 수집합니다. 구현 소스는 KOSIS API, KAMIS HTML, CJ제일제당 IR PDF로 제한합니다.

## 후보 평가

| 소스 | 형식 | MVP 용도 | 인증 | 상태 | 대체 소스 |
|---|---|---|---|---|---|
| KOSIS 통계자료 API | JSON | 식료품 제조업 생산·출하·재고 월별 지수 | API 키 | 키 신청 전 | ECOS 또는 KOSIS 파일 다운로드 |
| KAMIS 기간별 소매가격 | HTML | 날짜·가격·등락률 | 없음 | 실제 HTTP 응답 확인 | aT 기간별 소매가격 API |
| CJ제일제당 IR | 텍스트 PDF | 분기 실적표 한 개 | 없음 | 공식 PDF와 텍스트 확인 | 다른 분기 또는 지속가능경영보고서 |
| aT 기간별 소매가격 API | JSON/XML | KAMIS 값 교차 검증 및 장애 대체 | 공공데이터포털 키 | 키 신청 전 | KAMIS HTML |

## KAMIS 실제 요청 결과

2026-11-16에 기간별 소매가격 예시 URL을 `GET`으로 호출했습니다.

- HTTP 상태: `200`
- 콘텐츠 유형: `text/html; charset=utf-8`
- 응답 크기: `104,063 bytes`
- `<table>`: 1개
- `<tr>`: 14개
- 열: `날짜`, `가격`, `등락률`
- JavaScript 실행 없이 응답 HTML에 데이터 행이 포함됨

따라서 MVP에서는 BeautifulSoup으로 수집할 수 있습니다. HTML은 API와 동일한 가격뿐 아니라 화면에 표시되는 등락률을 제공하므로 수집 목적이 있습니다. 같은 날짜와 품목의 가격을 aT API와 비교하는 교차 검증 규칙을 둡니다.

## KOSIS 확인 사항

- 통계자료 API는 인증키가 필요합니다.
- 시작·종료 수록시점 파라미터로 기간 백필이 가능합니다.
- 과거 생산·출하·재고 지수가 사후 변경된 공식 사례가 있어 재수집 변경 감지 규칙의 근거가 됩니다.

### 실제 API 확인

2026-11-16에 발급 키로 다음 계약을 확인했습니다.

- 기관: `101`
- 통계표: `DT_1F02031` 광역경제권/산업별지수(2020=100)
- 산업: `C10` 식료품 제조업
- 항목: `T10` 산업생산지수, `T11` 출하지수, `T12` 재고지수
- 주기: 월 `M`
- 단위: `2020＝100`
- 샘플 기간: `202601`~`202603`
- 결과: 54건

응답에는 광역권, 산업, 항목, 수록시점, 수치, 단위, 최종수정일이 포함됩니다. 자연키는 `광역권 코드 + 산업 코드 + 항목 ID + 수록시점`으로 설계합니다.

## CJ제일제당 IR PDF 확인 사항

- 공식 IR 페이지에서 2026년 3분기 PDF 다운로드가 가능합니다.
- 28페이지 텍스트 PDF이며 OCR이 필요하지 않습니다.
- 20페이지 요약손익계산서에는 매출액, 매출원가, 영업이익, 당기순이익 등이 있습니다.
- 2~3개 분기를 비교해 표의 페이지와 헤더 변경 여부를 확인한 뒤 추출 대상을 확정합니다.

## MVP 품질 규칙

1. 필수 필드 누락
2. 자연키 중복
3. 직전 성공 실행 대비 건수 급감
4. 전월 또는 전일 대비 값 급변
5. 요청 기간의 시점 누락
6. KAMIS HTML과 aT API 동일 날짜·품목 가격 불일치

백필 재실행 결과 일치는 별도 통합 테스트로 검증합니다.
