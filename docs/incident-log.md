# 개발 장애 기록

## 2026-11-16 — Python 명령이 실행되지 않음

- 증상: `python`과 `py` 명령으로 인터프리터를 실행할 수 없었습니다.
- 원인: PATH의 `python.exe`가 Microsoft Store 실행 별칭을 가리켰고, Python Launcher가 실제 Python 3.13 설치를 찾지 못했습니다.
- 조치: 설치 경로의 `Python313\python.exe`로 프로젝트 가상환경을 생성했습니다.
- 재발 방지: README와 개발 명령은 `backend\.venv\Scripts\python.exe`를 기준으로 검증합니다.

## 2026-11-16 — `.env`가 작업 저장소에서 발견되지 않음

- 증상: 키를 입력한 뒤에도 애플리케이션에서 두 환경변수를 읽지 못했습니다.
- 원인: 같은 저장소의 복제본이 두 곳에 있어 작업 경로가 혼동됐고, 처음에는 현재 작업 저장소에 `.env`가 저장되지 않았습니다.
- 조치: 실제 작업 경로를 확인하고 저장소 루트에 `.env`를 만들었습니다.
- 재발 방지: VS Code와 CLI에서 동일한 저장소 루트를 사용하고, 시작 시 현재 경로와 Git 원격을 확인합니다.

## 2026-11-16 — 패키지 설치가 중간 상태로 종료됨

- 증상: 첫 설치 뒤 `pytest`와 `typer`를 가져오지 못했습니다.
- 원인: 의존성 다운로드가 완전히 끝나기 전에 설치 명령이 종료됐습니다.
- 조치: 동일한 editable 설치를 다시 실행하고 `pip check`와 전체 테스트로 검증했습니다.
- 재발 방지: 설치 로그의 성공 문구뿐 아니라 필요한 모듈 import와 테스트 실행으로 완료 여부를 확인합니다.
